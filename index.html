AI

はじめての生成AI

そもそも何？ から使い始めるまで

生成AIは、インターネット上の大量の文章や画像からことばや形のパターンを学び、質問や指示に合わせて新しい文章・画像・音声・プログラムを作り出すAIです。チャットで話しかけるように使えるので、専門知識がなくても今日から試せます。

これまでのAI
見分ける・予測する

迷惑メールの判定、商品のおすすめ、売上の予測など。決まった答えを選ぶのが得意。

生成AI
新しく作る

文章の下書き、要約、翻訳、画像づくり、プログラムなど。答えそのものを組み立てる。

INPUT
あなたの指示

「この文章を3行で要約して」などの質問や指示。プロンプトと呼ぶ。

→
MODEL
AIモデル（LLM）

学んだパターンをもとに「次に来そうなことば」を一つずつ予測して、答えを組み立てる。

→
OUTPUT
結果

文章、要約、画像、表、プログラムなど。何度でも直しを頼める。

「予測して組み立てる」しくみのため、事実と違う内容をもっともらしく書くことがあります（ハルシネーション）。大事な情報は必ず確かめましょう。

◯得意なこと

  • 文章を書く・直す・短くまとめる・言い換える
  • 外国語との翻訳、やさしい言葉での説明
  • アイデア出し、企画や文章の構成づくり
  • 表やプログラムの作成、写真や資料の読み取り

△苦手なこと

  • 最新の出来事や細かい数字を正確に答えること（検索機能で補える場合もある）
  • 出典をつけずに書いた内容の正しさを保証すること
  • 法律・医療・お金など、責任をともなう最終判断
  • あなたの会社や家庭だけの事情を、言われずに知ること

使い始める3ステップ

  1. 無料プランで試す多くのサービスは無料で始められます。メールアドレスなどでアカウントを作るだけです。
  2. 個人情報は入れない名前や住所、会社の秘密は入力しないのが基本。学習に使わせない設定も確認しましょう。
  3. 答えを確かめて使う出てきた答えは下書きとして扱い、事実や数字は公式の情報で確かめてから使います。

生成AI全般の良い点と注意点

◯良い点

  • 文章の下書き、要約、翻訳、言い換えを数秒で出せる
  • プログラミングや表計算の式づくりを対話しながら進められる
  • 調べものの入口として、論点や用語を整理してくれる
  • 画像・音声・資料の読み取りなど、文字以外も扱える
  • 24時間いつでも、何度でも質問し直せる

△注意点

  • もっともらしい誤り（ハルシネーション）を出すことがある
  • 入力した内容の扱いは契約プランで異なり、機密や個人情報には注意が要る
  • 著作権や商標をめぐる訴訟が各国で続いており、生成物の使い方に配慮が必要
  • 障害や仕様変更、無料枠の縮小が予告なく起こる
  • 任せきりにすると、判断の根拠を説明できなくなる

→使い道

  • 会議メモから議事録と次のタスクを作る
  • メールや案内文の下書き、敬語の調整
  • 長い規約・論文・報告書の要点抽出
  • アンケート自由記述の分類と傾向の整理
  • 学習の相棒（解説、練習問題、添削）

よく出てくる用語

プロンプトprompt
AIへの指示や質問の文。具体的に書くほど、ほしい答えに近づく。
LLM大規模言語モデル
大量の文章から学んだ、文章を扱うAIの本体。GPT、Gemini、Claude などがこれにあたる。
モデルmodel
AIの「頭脳」にあたる部分。同じサービスでも、速いモデル・賢いモデルなど種類がある。
ハルシネーションhallucination
AIが事実と違う内容を、もっともらしく答えてしまうこと。
マルチモーダルmultimodal
文章だけでなく、画像・音声・動画なども読み取ったり作ったりできること。
エージェントagent
指示を受けて、調べもの・操作・作業を自分で順に進めるAI。
トークンtoken
AIが文章を数える単位。料金や一度に読める量はトークン数で決まることが多い。
学習（トレーニング）training
データからパターンを覚えさせること。入力した内容が学習に使われるかはサービスと設定で違う。
オプトアウトopt-out
データを学習に使うことを、利用者が断ること。設定画面で選べる場合が多い。
APIapplication programming interface
自社のアプリやシステムからAIを呼び出すための窓口。使った量に応じて課金される。
公開モデルopen weights
中身（重み）が公開され、誰でも自分の環境で動かせるAIモデル。DeepSeek や Mistral が代表例。
AI検索answer engine
Webを検索し、結果をまとめて出典つきで答える仕組み。Perplexity が代表例。

よくある質問

無料でも使えますか？

多くは無料プランがあります。ただし使える回数やモデルに制限があり、ChatGPT の無料プランには広告が表示されます。Midjourney には無料プランがありません。詳しくは「料金・データ」をご覧ください。

日本語で使えますか？

ほとんどが日本語で使えます。Meta の Muse は2026年10月時点で日本では提供されていません。新しい機能は英語版から先に提供されることがあります。

仕事で使っても大丈夫ですか？

会社のルールを先に確認してください。顧客情報や社外秘を扱うなら、入力内容を学習に使わない法人向けプランが向いています。データが海外のどこに保存されるかも確認しましょう。

どれを選べばいいですか？

Googleのサービスをよく使うなら Gemini、Word や Teams を仕事で使うなら Copilot、長い資料やプログラミングなら Claude、調べものなら Perplexity、画像づくりなら Midjourney、まず何でも試したいなら ChatGPT が入りやすいでしょう。「AI診断」や「比較」も参考にしてください。

AIが作った文章や画像は自由に使えますか？

多くのサービスは利用者が使うことを認めていますが、既存の作品に似ていると権利の問題になることがあります。公開や販売の前に確認しましょう。

中国のAIサービスを使っても大丈夫ですか？

DeepSeek は入力したデータが中国のサーバーに保存され、中国の法令が適用されます。2025年2月に個人情報保護委員会が注意を呼びかけました。個人情報や仕事の情報は入力しないのが安全です。

使う前のチェックリスト

  • 入力してよい情報か顧客名、社外秘、個人情報は、会社の規程と契約プランのデータの扱いを確認してから入力する。
  • 事実の裏取り数字・日付・法律・引用文献は、必ず一次資料で確かめる。米国では裁判所への提出書類に架空の判例が含まれた事例が続いている。
  • 権利の確認生成した文章や画像を公開・販売する前に、既存の作品や商標に似ていないか見る。
  • 学習設定入力内容をモデルの改善に使わせない設定があるか確認する。
  • 代わりの手段障害で止まっても困らないよう、重要な業務は別のサービスか手作業の手順も用意しておく。

料金とデータの扱い

最終確認日 —

サービスを押すとプランごとの月額と、入力した内容が学習に使われるかが開きます。閉じたままでも最安の料金とデータの扱いを確認できます。各サービスに公式の料金ページへのリンクがあります。

料金を読み込んでいます…

月額は税・地域で変わります。米ドル表記のサービスは、日本での価格や税込額が異なることがあります。学習への利用を止めても、すでに学習に使われたデータは消えません。
