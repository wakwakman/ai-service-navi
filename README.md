# AIサービスナビ

主要な生成AIサービスの良い点と注意点、料金、データの扱い、運営会社、ニュースをまとめた案内サイトです。

## ファイル

- `index.html`：ページ本体
- `services.json`：各サービスの基本情報と比較項目
- `news.json`：サービス別・規制や社会の動きのニュース（毎週更新）
- `plans.json`：プランと料金、入力データの扱い（毎週確認）
- `companies.json`：運営会社の情報（毎週確認）

内容は公開されている報道・公式発表をもとにまとめたもので、正確さを保証するものではありません。利用前に各社の公式情報を確認してください。
